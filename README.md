# CalaSpace

CalaSpace is a web application focused on women's mental wellness and self-care. It provides a space for users to reflect on their emotions, explore wellness activities, and access features related to personal well-being.

## Features

- **Mood Journal** — Record moods and write personal journal entries.
- **Daily Affirmations** — Read daily affirmations.
- **Community** — Explore a space for sharing and connecting with others.
- **Relationship Check** — Explore relationship-related insights.
- **Psychologist Directory** — Browse psychologist profiles and consultation options.
- **Wellness Activities** — Explore activities such as Pilates, pottery, and flower arrangement.
- **Booking** — Explore the booking process for selected activities and services.
- **User Profile** — View and manage profile information.

## Built With

- HTML
- CSS
- JavaScript
- Local Storage

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No database or backend setup is required.

## Notes

CalaSpace is a frontend web project. Data for selected interactions is stored in the browser using `localStorage`. Features involving consultations, community interactions, and bookings are part of the current prototype and are not connected to live services.
